# 知桥

个人用的文献检索浏览器插件：CARSI / 知网 FSSO 选学校并代填本校 IdP，知网/维普/WoS 专业检索代填。

## 安装

1. 打开 [最新 Release](https://github.com/qwq243/zhiqiao-academic/releases/latest)，下载 `zhiqiao-academic.zip`
2. 解压
3. Chrome / Edge 打开扩展页，打开开发者模式
4. 「加载已解压的扩展程序」，选解压后的文件夹

更新清单：[`update.json`](./update.json)。插件会定期读这份文件。

不要把学号口令提交进这个仓库。
